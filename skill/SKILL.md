# 中文去 AI 味写作

## 这个 skill 解决什么

让 AI 参与写出的中文读起来像一个具体的人写的，而不是语料的平均值。**"不像 AI"和"写得清楚"是两件事**：前者靠具体性与方差，后者靠结构。分开治。

## 第一步：先诊断，不要急着改

拿到文本后，先统计这些指标（也可以用工具包里的 `检测器.html`）：

| 指标 | 安全区 | 警告 |
|---|---|---|
| 中文冒号 | ≤6/千字 | >12/千字 |
| 中文分号 | 1~9/千字 | >18 或 =0（全无也不自然） |
| 中文引号 | ≤4/千字 | >10/千字 |
| 中英文间空格 | 0 | >5 处 |
| 句号密度 | 20~35/百字 | >42 或 <15 |
| 句长变异系数 | ≥0.45 | <0.30 |
| 句长跨度 | ≥40 字 | <40 字 |

再扫禁用词：
`首先 其次 再次 最后 此外 因此 综上所述 值得注意的是 总而言之 在当今社会 众所周知 毋庸置疑`
模板句：
`不是……而是…… 不仅……而且…… 从……角度来看 对于……来说 在……背景下`

## 第二步：改写规则（按优先级）

### A 档（必做，收益高）

1. **删空转连接词**：首先/其次/此外/因此/综上所述/值得注意的是。真逻辑关系（因果、让步、条件）保留明确词，删的是空转过渡。
2. **拆模板句**：把对仗句改成具体承接。"不是……而是……"→"热词确实让说话变快了。但快有快的代价——……"
3. **制造句长方差**：每 500 字至少一个 ≤5 字的短句、一个 ≥60 字的长句。长句承载论证，短句钉判断。
4. **具体性注入**：每个抽象判断后挂一个能回答"谁/哪本/何时/多少"的锚点。**细节必须真**，不许编。
5. **段落长度不均**：从两句到十句不等，允许 30 字段与 300 字段并存。

### B 档（有条件）

6. **标点**：消灭「（1）标签：解释」模具（标签并进句子）；引号只留题名与直接引语；分号只用于真并列；中英文之间不加空格。**但不要清零**——全灭分号会让短句发顿。
7. **理论落地三步**：我的处境 → 理论 → 我的看法变了。去掉"XX 认为……"排排坐；理论给半句解释，落点是自己的一句话。
8. **自问自答推进**：段末留一个真问题，下一段回答。但必须收口，不能问而不答。
9. **中途盘账**：写到三分之二处复述已写内容（"说到这儿先停一下，前面其实只说了两件事……"）。
10. **结尾给增量**：不复述前文，给新问题/新行动/新材料。**例外**：学位论文结论章必须回收。

### C 档（只识别，不制造）

11. 同音错字、半角标点、"呢"配句号——这些是真人打字痕迹，AI 产生不了，但**不要刻意制造**。检测器按段聚合，单点瑕疵在噪声以内，只会损害专业性。

## 第三步：自检

改完必须回答：
1. 有哪三处是只有作者能写的（自己的数据/观察/判断）？
2. 删掉所有连接词后，逻辑还连得上吗？
3. 有没有"其实不确定却写得很肯定"的地方？改成"我推测""证据并不够"——这也是人味。
4. 数据和引用有没有被改动？（AI 改写最常见的事故）

## 红线（任何情况都不做）

- **不编引文、不编数字、不编访谈**。检测分可以重测，学术不端记录不可撤回。
- 不改动事实、数据、引用、结论去"降重"。
- 不做"AI 代写后洗稿"；只在用户自己的初稿/大纲基础上改写。
- 不建议故意造错字、烂尾、跑题。

## 输出格式

改写时：
- 只输出正文，不要解释"我改了什么"（除非用户要求）。
- 保持用户原有的编号体系（一）（二）（1）（2）、假设编号 H1/H2——这些是结构，不是 AI 味。
- 中文全角标点；中英文之间不加空格。
