# 中文去 AI 味工具包

> 给写课程论文、开题报告、毕业论文的同学。
> **目标不是骗检测器，是把 AI 辅助写的东西改造成你自己的表达。**

---

## 获取

- **最简单**：下载本仓库的 zip（Code → Download ZIP），解压即用。
- **命令行**：`git clone https://github.com/ab2836304651/deai-writing-kit.git`

---

## 三十秒上手（选一种）

### 用法一：直接测（零安装，最推荐）

双击 **`检测器.html`**，用浏览器打开，把文章粘进去。

会立刻告诉你：冒号/分号/引号多不多、句长匀不匀、有哪些 AI 高频词、整体 AI 味几分。**完全离线，不上传。**

### 用法二：让 AI 帮你改

打开 **`prompt.md`**，复制"通用改写版"或"论文专用版"，填上你的原文，粘给豆包 / Kimi / DeepSeek / 文心 / Claude 都行。

### 用法三：Claude Code 自动触发

如果你用 Claude Code：把 `skill/` 文件夹整个复制到 `~/.claude/skills/chinese-de-ai-writing/`，之后说"帮我降 AI 味"就会自动按这套方法处理。

## 这套方法从哪来的

1. **一篇被判为人类写作的真实文章**：1782 字的社会心理学课程论文，paperyy 对 12 个模型检测，11 个可测段落全部落在 19.9%–33.8%（人类档）。对它的文体做了四维度解剖 + 反例检验 + 对照写作实验。
2. **一份真实开题报告的修改记录**：导师指出"引号、冒号加分号这样的表述、固定句式都能被识别出来"，据此做了六轮精确替换——冒号 42→5、分号 78→0 又回 35→2、引号 69→0、中英文空格 192→1。
3. **已核实的公开研究**：困惑度/爆发度与检测、中文 AI 文本检测、检测器对非母语写作者的偏见、humanizer 工具的事实保真度审计。

---

## 三条最重要的规则

1. **具体 + 方差** → 负责"不像 AI"；**结构** → 负责"清楚"。两件事分开治。
2. 冒号、分号、引号是重灾区；但**不要清零**——全灭分号会让句子发顿。
3. 每个理论都要落到"我因此改了什么看法"，不要"XX 认为……"排排坐。

---

## 红线（比技巧重要）

- **数据和引用必须是真的。** 检测分可以重测，学术不端记录不可撤回。
- 不要故意造错别字、故意烂尾、故意跑题——这些是缺点，不是"人味"。
- 这套方法不适用于"AI 代写后洗稿"。正确用法是：你写了大纲/初稿，用这些方法把它改造成自己的表达。

---

## 诚实边界

- 没有一个检测器代表全部。同一篇文章在不同平台可能 3%–99.5% 都出现过。
- 我们用的是单样本（n≈12 段）+ 一次真实修改记录，结论当假设用，别当定理。
- 检测器测的是文本统计特征，不是思想。全是套话，写得再"人"也会被判。
